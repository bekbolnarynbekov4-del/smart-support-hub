# Руководство пользователя

## Назначение
Smart Support Hub — учебная система для учёта внедрений, инцидентов, заявок сопровождения и релизов.

## Как зарегистрировать инцидент
Откройте «Инциденты», нажмите «Новый инцидент», заполните описание и приоритет, затем сохраните запись.

## Как создать заявку на изменение
Откройте «Заявки», нажмите «Добавить заявку», укажите название, вид сопровождения, статус и целевую версию.

## Как отметить инцидент решённым
В таблице инцидентов нажмите «Решить» напротив нужной записи.

## Хранение данных
Записи сохраняются в localStorage текущего браузера. Очистка данных браузера может удалить учебные записи.
