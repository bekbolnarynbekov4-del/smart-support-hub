# Smart Support Hub

Учебный прототип платформы внедрения, эксплуатации и сопровождения программного продукта.

## Запуск
Откройте папку в Visual Studio Code и запустите `index.html` через расширение Live Server.

## Технологии
HTML5, CSS3, JavaScript, localStorage, Chart.js, GitHub Pages.

## Страницы
- Dashboard
- Deployments
- Incidents
- Maintenance
- Releases

Данные демонстрационные и хранятся в браузере пользователя через localStorage.
